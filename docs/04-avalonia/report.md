## 已实现功能

- `LogFields.Summary` 将每条远程日志的字段整理为可读文本，并能显示错误/未分析提示。
- Refresh 异步获取 Agent 文件列表并刷新左侧列表。
- Selected 按钮支持多选文件分析；新增 All 按钮分析全部文件；右键 Analyze File 支持分析单个文件。
- 右键 View Analysis Results 通过 gRPC 流式读取结果，并在右侧列表展示成功、失败和未分析状态。
- 所有 gRPC 操作都通过异步 API 调用，并对未连接、非法并行度、空选择、网络异常和 Agent 错误状态弹出提示。

## Q4.1

控制台程序按顺序读取输入并打印文本，界面程序则由事件驱动：用户操作触发命令，ViewModel 更新属性后由绑定系统刷新界面。GUI 还需要考虑布局、控件状态、多选同步、右键菜单、线程亲和性和异常提示等额外问题。若在 UI 线程上同步等待网络请求，窗口会失去响应，因此这里所有 gRPC 调用都使用异步 API 并 `await`，让 UI 线程在等待期间保持可用。

## Q4.2.b（使用 AI）

本次作业使用了 AI 辅助。提示词的核心内容是：阅读 Avalonia 的 XAML、ViewModel、对话框和 gRPC 客户端工厂，补全刷新、选中文件分析、全部分析、右键分析和结果显示，并保持 UI 线程不阻塞。AI 主要用于梳理 MVVM 绑定关系和异步流读取；编译时发现 C# 14 将 `field` 作为属性访问器关键字，随后将 lambda 变量改名并重新构建通过。
